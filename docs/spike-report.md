Wall-clock time of each command, 5 runs each (median, minimum, maximum), inside the tools container (12 CPUs, Linux kernel 6.18.33.2-microsoft-standard-WSL2), the library on a Docker named volume. The synthetic FLAC is white noise (two independent channels, 290 s): `ffmpeg -filter_complex 'anoisesrc=color=white:sample_rate=44100:amplitude=0.5:seed=1[l];anoisesrc=color=white:sample_rate=44100:amplitude=0.5:seed=2[r];[l][r]amerge=inputs=2' -t 290 -c:a flac -sample_fmt s16 /work/big.flac`. The full decode to `null` is there for comparison only. The fingerprint decodes nothing (`-c copy`): it reads the packets and hashes them with SHA-256, so its cost follows the size of the file; a decoder's cost depends on the codec (white noise makes a FLAC of almost verbatim frames, which decodes very fast).
