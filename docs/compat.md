# MusicLib compatibility

Vibrance reads only the `library/` folder of Vibrance MusicLib. This table lists the MusicLib versions each Vibrance version has been tested with, using the contract suite (`scripts/contract.sh`).

| Vibrance | MusicLib | Status |
|---|---|---|
| 0.1.0 (in development) | 1.1.0 | Target version. Not confirmed yet: the contract suite does not exist yet. |
